The first public release of **HorizonRadio** — your in-game soundtrack for Minecraft 1.7.10.

### Highlights

- **YouTube music:** search songs, discover and import playlists, and explore weekly country charts.
- **Listen together:** a shared server queue with synchronized song playback, drag-and-drop ordering, shuffle, repeat, and playback controls.
- **Live internet radio:** find stations through Radio Browser and tune in without leaving Minecraft.
- **Your favorites:** keep songs and radio stations close, with personal volume and interface settings.
- **Built for the game:** a two-column music screen, in-game notifications, and operator controls for queue and song-length limits.
- **Included audio backend:** no external media program or required GregTech/GTNHLib dependency.

### Installation

Download **`horizonradio-1.0.0.jar`** and put it in the `mods` folder on the server and every client. Requires **Minecraft 1.7.10 / Forge 10.13.4.1614**. Join a world and press **N** to open HorizonRadio.

The same JAR targets standalone Forge (Java 8-compatible runtime) and GTNH (Java 17+). Runtime smoke tests for those environments remain pending. Java 25 is needed only to build the mod. Each client needs internet access and a working audio device; live radio timing can differ between listeners. The shared queue is not saved across server restarts.

The accompanying `.sha256` file lets you verify the download. See the [README](https://github.com/Justronaut716/HorizonRadio#readme) for setup and features.
